# archive/

Everything superseded: earlier drafts, plans, working memos and experiments. Kept because the paper's history is part of its provenance, and frozen because it is history.

- **Nothing here is current.** For the paper, see `../paper/`.
- **Archived files are never edited.** If something here needs correcting, the correction goes in the current material, and `INDEX.md` notes it.
- **Every item has a row in [`INDEX.md`](INDEX.md):** what it was, when, why it was retired, what replaced it, and the commit where the replacement landed.

| Folder | Holds |
|---|---|
| `drafts/` | Earlier chapter drafts and the printed review sets made from them |
| `plans/` | Paper plans that were executed or superseded |
| `memos/` | Working memos, landscape scans, sweeps, proofreads and analyses from the drafting period |
| `experiments/` | Early experiments run during the work but not used by this paper |
