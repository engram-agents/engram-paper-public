# References

**Extraction rule for this file.** Every entry below was built *only* from metadata
read directly in a file under `paper_research/source_pdfs/` — a title page, copyright
page, journal running head, or arXiv identifier line in the document itself. No field
was supplied from memory, from inference, or from an external bibliographic database.
Where a source does not print a field, the field is **omitted**, and the entry carries a
trailing `[metadata incomplete: …]` marker naming exactly what is missing, so that a
later pass knows what to fill and a thin entry is never mistaken for a checked one.
Each entry names the source file it was read from.

A work cited in the chapters for which no file exists under `source_pdfs/` is **not
listed here at all** rather than reconstructed; those names are tracked separately and
still need sourcing.
